# Claude Bridge

Pannello chat di Claude dentro VS Code. Le risposte arrivano da una chat di claude.ai collegata al connector "VS Code Bridge" e messa in ascolto con «segui VS Code».

- `Ctrl+Alt+C` — chiedi a Claude (con la selezione)
- `Ctrl+Alt+E` — modifica la selezione con Claude (arriva un diff da accettare)
- Comando "Claude Bridge: Configura" — URL del server e token
